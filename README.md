## What it does

`main.py` writes a single roast line (121 characters, one line) about a smart
fridge's ice maker to `/output/entry.txt`. No network, no input files, no
dependencies — the line is a literal in the program, validated against the
competition gate (1–200 characters, one non-blank line) and verified by a
read-back before the program exits.

## The line

> My ice maker has unionized: one cube a day, no overtime, and it files a
> complaint every time I open the door for a snack.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
